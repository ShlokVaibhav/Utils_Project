# claude-skills

Skill files for Claude. Two variants per skill:

| File | Use with |
|---|---|
| `yt-sv-cli.md` | Claude Code (CLI) — copy to `~/.claude/commands/yt-sv.md`, invoke with `/yt-sv` |
| `yt-sv-web.md` | Claude.ai web — upload to a Project as a file, or paste into Project instructions |

## Setup

**CLI (Claude Code):**
```bash
cp claude-skills/yt-sv-cli.md ~/.claude/commands/yt-sv.md
```
Then use `/yt-sv` in any Claude Code session.

**Web (claude.ai):**
Open your Project → Add content → upload `yt-sv-web.md`, or paste its contents into the project instructions.
